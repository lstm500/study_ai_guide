# 算数ナビ AI先生（小学1〜3年）

文部科学省の小学校学習指導要領（算数）を骨格に、小学1〜3年の算数を「選定済み教材 → AI解説 → 練習 → 答案写真添削」につないだStreamlit試作版です。

## 今回の版のポイント

- 小1〜小3、合計44単元を収録
- すべての単元に教材を登録済み（ユーザーがYouTube等を探す必要はありません）
- 主教材はNPO法人eboardの単元別映像授業を中心に選定
- 図形、時計、グラフ、そろばん等は教育委員会・学習系YouTube・無料Web教材も補助教材として登録
- 各学年に北海道教育委員会の単元別練習問題への入口を用意
- 「教材とAI先生」から、登録済み教材をAIに読み込ませて質問可能
  - YouTube：字幕を取得できる場合は字幕を根拠に解説
  - Web教材：公開ページ本文を取得できる場合は本文を根拠に解説
  - 自動取得できない場合も、登録済みの単元目標・学習ポイントを基準にAI解説
- 答案写真をアップロードしてAI添削

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

## AI機能

AI先生、選定済み教材への質問、答案画像添削にはOpenAI APIキーが必要です。

環境変数:

```bash
OPENAI_API_KEY=...
```

またはStreamlit CloudのSecretsに以下を設定します。

```toml
OPENAI_API_KEY = "..."
```

APIキーがなくても、学年別カリキュラム、単元の目標、選定済み教材、学習済みチェックは利用できます。

## カリキュラムの基準

- 文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」
- 主教材：NPO法人eboard
- 補助教材：教育委員会等の公開YouTube、無料学習教材
- 練習問題：北海道教育委員会「チャレンジテスト 単元別問題」

教科書会社によって単元名や掲載順は異なるため、アプリでは学習内容を理解しやすい単位に整理しています。
